Integrations

All optional. Aurum works with none of them: you can type everything in. Anything you enter in Settings is stored encrypted on this computer and never sent back to the browser.

AI assistant (Anthropic or OpenAI)

  1. Create an API key at console.anthropic.com or platform.openai.com.
  2. Assistant → settings → Model and behaviour. Pick the provider and paste the key. (Or put ANTHROPIC_API_KEY / OPENAI_API_KEY in a .env file; copy .env.example.)
  3. Watch cost: Settings shows a 30-day usage table. Analyses are only re-run when your numbers change.

Only the assistant and the optional AI categoriser call these services, and only with the data needed for that question. Without a key those features simply stay off.

Statements by e-mail (Gmail)

Reads statement e-mails and their PDF attachments. It only reads; it cannot send or delete. How the statements are then interpreted is on the Any bank page.

  1. Turn on 2-Step Verification on your Google account.
  2. Google Account → Security → App passwords → create one named "Aurum".
  3. Settings → Gmail Email Sync → enter your address and the 16-character code → Connect with App Password.
  4. Tell it which e-mails are statements: for a card, Cards → Add card (sender address, a subject word, the PDF password if there is one). For a bank account, Settings → Bank accounts → the sender and subject word.

Prefer Google sign-in over an app password? See GMAIL-SETUP.md for the OAuth route.

Interactive Brokers (read-only)

  1. Client Portal → Performance & Reports → Flex Queries → create an Activity Flex Query containing Account Information, Open Positions, Cash Report (XML).
  2. Flex Web Service → enable it and copy the token; note the query ID.
  3. Settings → Interactive Brokers → paste both. Positions and cash sync on a schedule. Aurum cannot trade.

eToro (read-only)

  1. eToro → Settings → Trading → API Key Management.
  2. Create a key for the Real environment with Read permission only.
  3. Paste the keys under Settings → eToro. Syncs every six hours; leveraged, short and copy-trading positions are skipped.

Payslips

Income page → set the sender and PDF password for your payroll e-mails; Aurum reads gross, net, allowances and deductions from two-column (earnings left, deductions right) and single-column layouts. If yours is not recognised, enter income manually in the Budget.

Phone alerts

See the phone guide. Alerts are for new statements and rare market moves only.
