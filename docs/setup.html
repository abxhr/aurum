Set up

About ten minutes. Aurum runs on your own computer and listens only on that computer.

What you need

  • Windows, macOS or Linux.
  • Python 3.11 or newer (developed on 3.14). On Windows, tick "Add Python to PATH" in the installer.
  • Git, to download and update the code (or download the repository as a zip).

1 · Get it running

  1. Download the code.
    git clone https://github.com/abxhr/aurum.git aurum
cd aurum
  2. Start it. The first run creates a private Python environment, installs the requirements and starts the server (a few minutes). 
    # Windows
run.bat

# macOS / Linux
chmod +x run.sh
./run.sh
  3. Open http://localhost:5000 in a browser on the same computer.
  4. Set a password and your currency. Use 12 or more characters; a few random words is easy to remember and hard to guess. There is no account and no sign-up: this password only protects this computer's copy.

Just looking? On the sign-in page press Open the demo instead. It shows an invented year of data and never touches yours.

2 · Make it yours

  1. Settings (bottom of the sidebar). Set the app name, currency and monthly income. Choose the currency before you enter anything: changing it later relabels amounts, it does not convert them. Exchange rates for other currencies are fetched automatically.
  2. Preferences. Payday, whether statement dates are day-first or month-first, your home country (charges there are not counted as trips) and your time zone (for market hours).
  3. Your names. Optional. Your first name lets the Bank page recognise transfers to yourself; family names label money sent to family.
  4. Add holdings. Portfolio → Add holding. Pick a type, then either a ticker or fund code (priced live) or a value you type in.
  5. Tell the assistant about you (Assistant → settings → About you): goals, risk, and investing rules such as "index funds only" or "no tobacco". It reads this every time.
  6. Bring in your banks and cards: CSV import or statement e-mails. Then brokers and AI keys if you want them.

3 · Keep it running in the background

Windows

Run install-windows-background.bat once. It registers a hidden scheduled task that starts Aurum at sign-in and restarts it if it stops, and it locks the data folder to your Windows account. Logs are in data\logs. Remove it with powershell -ExecutionPolicy Bypass -File scripts\install-background.ps1 -Remove.

macOS / Linux

Run the production server (waitress, bound to 127.0.0.1) under whatever you normally use, for example a systemd user service:

[Unit]
Description=Aurum
[Service]
WorkingDirectory=%h/aurum
ExecStart=%h/aurum/.venv/bin/python backend/serve.py
Restart=always
[Install]
WantedBy=default.target

4 · Your data

  • Everything lives in data/: portfolio.db (one SQLite file) parsers/ (your private reader plugins) and, on macOS/Linux, secrets.key. None of it is ever committed; .gitignore excludes them.
  • Backup: Settings → Backup → Download. It contains your data without sign-in material (no password hash, sessions, passkeys or keys).
  • Moving computers: copy data/portfolio.db. Keys sealed on Windows (DPAPI) only open on the same Windows account; re-enter them on the new machine.
  • Update: git pull, then start it again. Tables upgrade themselves.

5 · Check it works

python backend/test_security.py
python backend/test_basics.py
python backend/test_repo_clean.py

Run them with the project's Python (.venv\Scripts\python on Windows, .venv/bin/python elsewhere). Each prints a pass line; any failure exits non-zero.

Troubleshooting

ProblemFix
"Address already in use"Another copy is running. Close it, or start with another port: PORT=5050 ./run.sh (Windows: set PORT=5050 first). Use that port in the address.
Browser says "not found" on a custom addressThe app answers only to localhost, 127.0.0.1 and your private Tailscale name. This blocks DNS-rebinding attacks. Use one of those.
Forgot the passwordStop the app, then run sqlite3 data/portfolio.db "DELETE FROM settings WHERE key='pw_hash'". The app starts in setup mode and asks for a new one. Your data is untouched.
A price shows a dashPrices come from Yahoo Finance, which sometimes rate-limits. Press Sync prices again later, or type a value by hand.
Currency looks wrong after changing itChanging currency relabels, it does not convert. Re-enter amounts, or set it back.
